# علتي (Elty)

تطبيق لمشاركة مواقع أفراد العيلة على خريطة واحدة. بيشتغل كموقع (PWA) وكتطبيق أندرويد (Capacitor) بتتبع في الخلفية.

## المميزات

- حسابات بإيميل وباسورد، والعيلة بتتحدد بكود سري (بيتخزن مهشّر SHA-256).
- خريطة بمواقع الكل مع آخر تحديث ومستوى البطارية 🔋.
- أماكن مهمة (البيت/الشغل/الجامعة) بنطاق بالمتر: إضافة وتعديل ✏️ ومسح.
- إشعارات وصول ومغادرة الأماكن، وتنبيه لما حد يقفل الموقع.
- زرار 🆘 طوارئ بيبعت للعيلة كلها مع الموقع الحالي.
- قفل بالبصمة (أندرويد) وتسجيل خروج 🚪.

## الإعداد (Firebase: مشروع `elty-fc7d6`)

1. Authentication → Sign-in method: فعّل **Email/Password**.
2. Firestore Database: اعمل Database.
3. Firestore → Rules: الصق محتوى `firestore.rules` واضغط **Publish**.
   **مهم:** انشر القواعد *قبل* ما ترفع نسخة `index.html` الجديدة، لأن البطارية وأنواع الأحداث الجديدة (`leave` و`sos`) مش مسموحة في القواعد القديمة.
4. فعّل GitHub Pages للريبو، وضيف الدومين في Authentication → Settings → Authorized domains.

## نسخة الأندرويد

بتتبني أوتوماتيك من `.github/workflows/build-apk.yml` وبتتنشر كـ Release باسم `latest` (ملف `elty.apk`).
التوقيع بمفتاح ثابت في `signing/elty.keystore` عشان التحديثات تتثبت فوق القديمة.

## ملاحظات أمان

- مفتاح الـ API بتاع Firebase معمول يبقى public، والحماية الحقيقية في `firestore.rules`.
- الكود السري للعيلة هو الحاجز الوحيد قدام التسجيل، فخليه طويل وماتشاركوش برّه العيلة.
- App Check لسه مش مفعّل.
